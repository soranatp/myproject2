# Project Collaboration with GitHub (Team Assignment)

โครงการนี้จัดทำขึ้นเพื่อใช้ในการเรียนรู้และฝึกทักษะ  
**การทำงานร่วมกันด้วย Git และ GitHub (Team Collaboration)**  
ตามกระบวนการทำงานของนักพัฒนาซอฟต์แวร์ในสถานประกอบการจริง

รายวิชา: การพัฒนาระบบร่วมกันด้วยแพลตฟอร์ม  
ระดับชั้น: ปวช. 2  
สถานศึกษา: วิทยาลัยเทคนิคอุทัยธานี  

---

## 🎯 วัตถุประสงค์ของโครงการ
ผู้เรียนสามารถ
- ทำงานร่วมกันเป็นทีมโดยใช้ GitHub
- ใช้ Issue ในการกำหนดงานและมอบหมายหน้าที่
- สร้าง Branch เพื่อพัฒนาแยกจากงานหลัก
- Commit, Push และ Pull Request ได้อย่างถูกต้อง
- เรียนรู้บทบาทหน้าที่และความรับผิดชอบในทีมพัฒนา

---

## 👥 รูปแบบการทำงาน (งานคู่)
นักศึกษาทำงานเป็น **ทีมละ 2 คน** โดยแบ่งบทบาทดังนี้

- **Issue Owner (คนที่ 1)**  
  รับผิดชอบการเปิด Issue, มอบหมายงาน (Assignee), ตรวจ Pull Request, Merge และ Close Issue

- **Developer (คนที่ 2)**  
  รับผิดชอบการสร้าง Branch, แก้ไขไฟล์, Commit และ Push งานขึ้น GitHub

> ❗ ห้ามสลับบทบาทกันโดยไม่ได้รับอนุญาตจากครูผู้สอน

---

## 🛠 เครื่องมือที่ใช้
- Git
- GitHub
- Web Browser หรือ Git Bash

---

## 📌 แนวทางการทำงาน
นักศึกษาทุกทีมต้องปฏิบัติงานตามขั้นตอนดังนี้

1. Fork Repository นี้ไปยังบัญชี GitHub ของทีมงาน  
2. **Issue Owner** เปิด Issue เพื่อกำหนดงาน  
3. **Developer** สร้าง Branch ตามรูปแบบที่กำหนด  
4. Developer แก้ไขไฟล์ README.md เพิ่มข้อมูลทีม  
5. Commit และ Push งานขึ้น GitHub  
6. Issue Owner สร้าง Pull Request เพื่อตรวจงาน  
7. Merge งานเข้ากับ branch main และ Close Issue

## ⚠️ ข้อควรปฏิบัติ
- ห้ามแก้ไขไฟล์บน branch `main` โดยตรง  
- ต้องสร้าง Branch ของทีมก่อนแก้ไขงาน  
- ทุกการแก้ไขต้องมี Commit message ที่ชัดเจน  
- การส่งงานต้องผ่าน Pull Request เท่านั้น  
- หลัง Merge แล้ว ต้อง Close Issue ทุกครั้ง
